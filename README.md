# Портфолио — Андрей Хлоповских

Статический сайт: обычные HTML, CSS и JavaScript без сборки и без зависимостей.
Всё лежит внутри — шрифты, картинки, скрипты. Из интернета ничего не загружается.

**Важно:** перед открытием архив нужно распаковать (правой кнопкой → «Извлечь всё»).
Если открыть `index.html` прямо из архива, Windows достанет только этот файл без папок
`css`, `js`, `fonts`, `images` — и страница развалится. Для быстрого просмотра без распаковки
есть `portfolio.html` рядом с этой папкой: в нём весь сайт одним файлом.

## Что где лежит

```
index.html          вся разметка страницы
css/fonts.css       подключение шрифтов из папки fonts/
css/style.css       стили и анимации (разбиты на разделы с заголовками)
js/data.js          данные проектов и документов — правь здесь
js/main.js          поведение: разделы, орбиты, просмотрщик, курсор
fonts/              шрифты Unbounded, Onest, JetBrains Mono (SIL Open Font License)
images/             фото, иконки приложений, скриншоты, сертификат
favicon.svg         иконка вкладки
.nojekyll           говорит GitHub Pages отдавать файлы как есть
```

### Как добавить или изменить проект
Открой `js/data.js`. Каждый проект — один объект в списке `PROJECTS`.
Скопируй любой, поменяй поля, а скриншоты положи в
`images/projects/<имя>/thumbs/` (превью ~420 px шириной) и `images/projects/<имя>/full/` (оригиналы).
Первые три проекта летают по внутренней орбите, остальные — по внешней.
`wip: true` делает полупрозрачную планету с «?» («В разработке»).

## Как выложить на GitHub Pages (бесплатно)

1. Зайди на github.com под своим аккаунтом **AndryK1**.
2. Создай новый репозиторий с именем ровно **`AndryK1.github.io`** (Public).
3. В репозитории: **Add file → Upload files** → перетащи туда *содержимое* этой папки
   (`index.html`, папки `css`, `js`, `fonts`, `images`, файлы `favicon.svg`, `.nojekyll`) → **Commit changes**.
   Если `.nojekyll` не видно в проводнике — включи показ скрытых файлов; без него сайт тоже заработает.
4. **Settings → Pages**: в «Build and deployment» выбери *Deploy from a branch*, ветка **main**, папка **/(root)** → **Save**.
5. Через 1–2 минуты сайт откроется по адресу **https://andryk1.github.io**.

Обновлять сайт — так же: загрузи изменённые файлы поверх старых и сделай Commit.

### Домен
Файл `CNAME` говорит GitHub Pages, что сайт живёт на `developer-android.ru`.
Адрес сайта и картинка для превью ссылки уже прописаны в `index.html` (`canonical`, `og:url`, `og:image`).

## Свой домен (по желанию)

1. Купи домен у регистратора (например, REG.RU или RU-CENTER).
2. В панели регистратора, в DNS-записях домена, добавь четыре A-записи для `@`:
   `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   и CNAME-запись `www` → `andryk1.github.io`.
3. На GitHub: **Settings → Pages → Custom domain** — впиши домен и нажми **Save**.
4. Когда появится галочка **Enforce HTTPS** (бывает, что ждать до суток) — включи её.

## Одиночный файл portfolio.html

Тот же сайт, где стили, скрипты, шрифты и картинки вшиты внутрь (≈ 4,9 МБ). Его удобно
отправить файлом или открыть без распаковки. Для публикации в интернете лучше папка:
там скриншоты грузятся по мере надобности, а не все сразу.
Если поменяешь что-то в папке и захочешь обновить одиночный файл:
`python build_single_file.py portfolio-site portfolio.html`.

## Производительность

- Анимируются только `transform` и `opacity` — их считает видеокарта, страница не пересчитывается.
- Курсор-комета: события мыши только запоминают координаты, движение считается раз в кадр,
  сглаживание учитывает длительность кадра (без рывков при пропусках), цикл засыпает, когда курсор стоит.
- Анимации hero и бегущей строки ставятся на паузу, когда их не видно на экране.
- На слабых устройствах (≤ 4 ядер или ≤ 4 ГБ памяти) и на телефонах фон автоматически спокойнее.
- Скриншоты в ленте — лёгкие превью с ленивой загрузкой, оригиналы грузятся только в полноэкранном просмотре.
- Учитывается системная настройка «уменьшить движение».

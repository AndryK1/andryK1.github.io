02 — ОПЫТ
фев 2024 — мар 2026 2 года 2 месяца · Воронеж

ООО НПП «Азимут»

Android-разработчик · корпоративное приложение складского учёта, 4 ключевых экрана
×4 сократил время загрузки экрана: с 4–5 c до менее чем 1 c
−60% потребление памяти на устройстве
≈2× быстрее еженедельная ревизия — по словам пользователей
СКЛАД

Список оборудования с поиском по названию, артикулу и производителю, фильтрами по категориям и статусами остатков. Весь UI — Compose, состояние через ViewModel + StateFlow по MVVM.

ПАГИНАЦИЯ

Paging 3 (PagingSource + RemoteMediator): категории на 300+ позиций грузятся порциями по 20 вместо всего списка разом.

ОФЛАЙН И СЕТЬ

Retrofit2 + OkHttp-интерцепторы, Room-кэш карточек как источник для RemoteMediator — работает на нестабильном складском Wi‑Fi без потери данных.

ДАШБОРД

Сам предложил график «Оборудование по категориям», согласовал требования с аналитиком и сделал bar-chart на Compose.

Стажировка — мобильная разработка (Android) · команда из 4 человек

Экран на Compose с постраничной загрузкой через Paging: никаких подвисаний при росте списка.
